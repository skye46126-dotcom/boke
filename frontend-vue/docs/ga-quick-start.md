# Google Analytics 快速配置指南

**目标**：5分钟内完成 Google Analytics 配置

---

## 📋 准备工作

需要的东西：
- ✅ Google 账号（Gmail）
- ✅ 网站域名（或 localhost 测试）
- ✅ 5分钟时间

---

## 🚀 配置步骤（共5步）

### 步骤 1：创建 Google Analytics 账号

**1.1 访问 Google Analytics**

打开浏览器，访问：
```
https://analytics.google.com/
```

**1.2 登录 Google 账号**

使用您的 Gmail 账号登录

**1.3 点击"开始衡量"按钮**

如果是第一次使用，会看到一个大大的"开始衡量"按钮，点击它。

---

### 步骤 2：设置账号

**2.1 账号名称**
- 输入：`个人作品集` 或任何您喜欢的名称
- 这个只是给您自己看的，随便取

**2.2 数据共享设置**
- 全部保持默认勾选 ✅
- 点击"下一步"

---

### 步骤 3：设置媒体资源

**3.1 媒体资源名称**
- 输入：`我的作品集网站`

**3.2 报告时区**
- 选择：`(GMT+08:00) 中国时间 - 北京`

**3.3 币种**
- 选择：`人民币 (CNY) - ¥`

**3.4 点击"下一步"**

---

### 步骤 4：填写业务信息（随便选）

这一步随便填，不影响使用：

**4.1 行业类别**
- 选择：`技术` 或 `计算机与电子产品`

**4.2 业务规模**
- 选择：`小型 - 雇员人数为 1-10 人`

**4.3 如何使用 Google Analytics**
- 勾选：`衡量客户互动情况`
- 或者随便勾一个

**4.4 点击"创建"**

**4.5 接受服务条款**
- 勾选 ✅ 同意条款
- 点击"我接受"

---

### 步骤 5：创建数据流（重要！）

**5.1 选择平台**

会看到三个选项：
- iOS 应用
- Android 应用  
- **网站** ← 选这个！

**5.2 填写网站信息**

**网站网址**：
- 如果已有域名：输入 `https://yoursite.com`
- 如果还在开发：输入 `http://localhost:5173`

**数据流名称**：
- 输入：`主网站`

**5.3 点击"创建数据流"**

---

## 🎯 获取 Measurement ID

创建数据流后，您会看到一个页面，上面显示：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━
衡量 ID
G-XXXXXXXXXX    [复制]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**点击"复制"按钮**，复制这个 ID！

例如：`G-ABC123DEF4`

> ⚠️ **重要**：这个 ID 很重要，保存好！

## 💻 更新代码

### 找到文件

打开项目中的这个文件：
```
frontend-vue/index.html
```

### 查找并替换

**在文件中找到**（有两处）：
```html
G-XXXXXXXXXX
```

**替换为**您刚才复制的 ID，例如：
```html
G-ABC123DEF4
```

### 具体位置

**第 1 处**（第 12 行左右）：
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-ABC123DEF4"></script>
                                            改这里 ↑
```

**第 2 处**（第 17 行左右）：
```javascript
gtag('config', 'G-ABC123DEF4');
             改这里 ↑
```

### 保存文件

按 `Ctrl+S` (Windows) 或 `Cmd+S` (Mac) 保存

## ✅ 验证是否成功

### 方法 1：实时报告（最简单）

**步骤**：
1. 访问您的网站（http://localhost:5173 或您的域名）
2. 打开 Google Analytics
3. 左侧菜单 → 点击 **"实时"**
4. 应该看到 **1 个活跃用户**（就是您自己！）

**如果看到了，说明成功！** 🎉

---

### 方法 2：浏览器检查（技术向）

1. 打开您的网站
2. 按 `F12` 打开开发者工具
3. 切换到 **Network（网络）** 标签
4. 刷新页面
5. 在搜索框输入 `google-analytics`
6. 应该看到请求发送成功

## ❓ 常见问题

### Q1: 找不到"开始衡量"按钮？

**A**: 可能您之前创建过账号，直接点击左下角的 ⚙️ **"管理"** → **"创建账号"**

---

### Q2: 实时报告显示 0 个用户？

**A**: 检查以下几点：
1. ID 是否正确替换了两处？
2. 文件是否保存了？
3. 浏览器是否有广告拦截器？（暂时禁用试试）
4. 等待 1-2 分钟，数据有延迟

---

### Q3: 本地测试会被记录吗？

**A**: 会的！在 localhost 开发时，您的访问也会被记录。

**解决方法**（可选）：
- 安装浏览器扩展 "Block Yourself from Analytics"
- 或者在 GA 设置中添加 IP 过滤

---

### Q4: 需要 Cookie 同意吗？

个人作品集通常不需要。

**但如果**您的网站面向欧盟用户（GDPR），需要添加 Cookie 同意横幅。

---

### Q5: 何时能看到完整数据？

**实时数据**：立即（1-2分钟延迟）
**历史数据**：24-48 小时后

## 📊 查看数据

### 访问 Google Analytics

```
https://analytics.google.com/
```

### 主要功能

**1. 实时报告**
- 查看当前有多少人在线
- 他们在看哪些页面

**2. 访问概览**
- 每天/每周/每月的访问量
- 访客来自哪里（搜索引擎、社交媒体等）

**3. 页面浏览量**
- 哪个页面最受欢迎
- 用户停留时间

**4. 用户设备**
- 桌面 vs 手机访问比例
- 浏览器类型
