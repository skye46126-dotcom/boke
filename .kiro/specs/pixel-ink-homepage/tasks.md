# 实现计划：像素水墨风+扑克牌素材个人主页

## 概述

基于详细需求文档，将现有的 Next.js 项目首页改造为像素水墨风+扑克牌素材的个人主页，采用"乱中有序便当盒布局"，兼顾视觉个性与实用性。

## 任务列表

- [x] 1. 建立核心样式系统和主题变量
  - 创建像素水墨风色彩体系（石青#4a7a96、赭石#8c6b48等6个核心色值）
  - 实现像素肌理规范（1px/2px边框、2px圆角、像素化渲染）
  - 配置水墨底色纹理系统（深色模式8×8px网格、浅色模式淡墨弥散）
  - _需求: 1.1, 1.2, 1.3_

- [x] 2. 实现核心锚点模块（头像+滚动字幕）
  - [x] 2.1 创建响应式头像容器组件
    - 支持圆形像素头像
    - PC端200×200px，平板端160×180px，移动端120×140px
    - _需求: 2.2, 3.2_

  - [x] 2.2 实现滚动字幕动画系统
    - 文字循环切换："正在构建我的数字世界..."等3条内容
    - 8s线性循环滚动动画（PC端），平板6s，移动端5s
    - 像素字体，颜色#4a7a96，容器overflow:hidden
    - _需求: 2.2, 4.0_

- [x] 3. 开发顶栏导航模块
  - [x] 3.1 创建扑克牌样式导航卡片
    - 4个导航项：文章、关于、项目、GitHub
    - 80×110px迷你扑克牌样式，像素字体14px
    - 花色替换为对应像素图标（书型、个人、齿轮、Git）
    - _需求: 2.5, 3.1_

  - [x] 3.2 实现导航卡片交互动效
    - hover：放大至85×115px + 抖动动画 + 石青发光边框
    - click：下沉效果 + 闪烁动画 + 页面跳转
    - PC端轻微错落布局，移动端转为底部抽屉式
    - _需求: 4.0_

- [x] 4. 构建功能卡片系统（四象限布局）
  - [x] 4.1 实现卡片基础组件和样式
    - 三种尺寸：小150×200px、中225×300px、大300×400px
    - 扑克牌样式，边框2px solid #2c2c2c
    - 像素化阴影效果，无模糊仅偏移
    - _需求: 1.4, 2.3, 3.3_

  - [x] 4.2 开发最新文章卡片
    - 标题（像素字体18px）+ 摘要（2行省略）+ 发布时间（12px）
    - hover时上移6px + 赭石边框高亮
    - 左下象限，上移3px + 旋转+1°（仅PC端）
    - _需求: 2.3, 3.3_

  - [x] 4.3 创建抽卡机卡片
    - 仅显示卡背素材，右上角"抽卡"文字（12px像素字体）
    - 点击弹出抽卡弹窗，扑克牌翻转动画
    - 右上象限，下移4px + 旋转-2°（仅PC端）
    - _需求: 1.4, 2.3, 4.0_

  - [x] 4.4 实现作品集卡片
    - 项目缩略图（像素化）+ 项目名（像素字体）+ 技术栈（12px）
    - 轻微堆叠效果（z-index分层），模拟叠放感
    - 右下象限，左移5px + 旋转+2°（仅PC端）
    - _需求: 2.3, 3.3_

- [x] 5. 开发侧边栏模块
  - [x] 5.1 创建侧边栏基础布局
    - 固定定位240px宽度，移动端默认隐藏
    - 添加显示/隐藏按钮（32×32px），平滑过渡动画
    - z-index: 998，确保层级正确
    - _需求: 2.1, 2.4_

  - [x] 5.2 实现个人信息卡模块
    - 80×80px像素头像 + 昵称（像素字体）+ 签名（12px）

    - _需求: 2.4, 3.4_

  - [x] 5.3 开发主题设置模块
    - 深色/浅色模式切换按钮（像素方块样式）
    - 选中态边框3px solid #4a7a96
    - 与现有ThemeToggle组件集成
    - _需求: 3.4_

  - [x] 5.4 创建文章标签云和阅读统计
    - 标签：前端开发/像素设计/作品集，像素字体12px
    - 标签背景#333，边框1px solid #555，hover时背景#444
    - 阅读统计：总文章数/总阅读量，像素图标+文字
    - _需求: 3.4_

- [x] 6. 实现抽卡弹窗系统
  - [x] 6.1 创建弹窗基础组件
    - 弹窗弹出动画（opacity 0→1，0.3s ease）
